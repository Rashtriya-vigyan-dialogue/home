🧬 Project Nematoda

Draft Proposal OPEA Integrated UN Genie.ai Aligned Open Source

Project Nematoda is a technical proposal designed by Rashtriya Vigyan Dialogue for a modular, open-source engine capable of detecting, evaluating, and flagging misleading content across multi-modal social media streams in real-time. By utilizing the Open Platform for Enterprise AI (OPEA) ecosystem and adhering to the United Nations Genie.ai Framework for ethical, transparent, and distributed AI, Nematoda aims to deliver an enterprise-grade moderation microservice.

🏛️ Organizational & Framework Foundations

1. Rashtriya Vigyan Dialogue Initiative

Project Nematoda serves as an architectural blueprint deliberated within Rashtriya Vigyan Dialogue to provide public digital infrastructure against automated misinformation, synthetic media, and cognitive manipulations.

2. UN Genie.ai Framework Alignment

In accordance with the UN's Genie.ai Framework principles for global AI safety and digital equity, Nematoda incorporates:

  • Human-in-the-Loop Oversight: Automated risk scores trigger human verification gates prior to action enforcement.
  • Explainability & Auditability: Every detection decision outputs structured, human-readable justification traces alongside a tamper-evident audit log.
  • Hardware Agnosticism & Sovereignty: Can be deployed across low-cost edge infrastructure, on-premises accelerators, or cloud-native setups without vendor lock-in.
  • Interoperable Public Goods: Standardized OpenAPI interfaces allow integration with sovereign fact-checking registries and civil society platforms.

⚡ Core Engine Features

Component Technology Stack Description
Ingestion Layer FastAPI / Redis Streams High-throughput ingestion handling textual posts, image artifacts, and video transcription metadata.
RAG Verification Engine OPEA VectorDB (Milvus/Qdrant) Retrieves verified claims and authoritative scientific datasets to evaluate factual consistency.
Misleading Risk Scoring vLLM / TGI Inference Engine Executes multi-step reasoning models to assign a claim confidence score (0.0 to 1.0) with granular tags.
Audit & Logging PostgreSQL / OpenTelemetry Generates reproducible execution logs conforming to UN Genie.ai transparency standards.

🚀 Proposed Quick-Start Setup

Note: The following deployment sequence is part of the experimental technical preview under deliberation.

1. Repository Setup

git clone https://github.com/rashtriya-vigyan-dialogue/project-nematoda.git
cd project-nematoda

2. OPEA Stack Orchestration

Launch the core OPEA services along with the Nematoda engine via Docker Compose:

# Copy environment configuration
cp .env.example .env

# Deploy OPEA microservices mesh
docker compose -f docker/docker-compose.nematoda.yaml up -d

3. Executing a Sample Analysis

curl -X POST "http://localhost:8080/v1/nematoda/evaluate" \
     -H "Content-Type: application/json" \
     -d '{
           "platform": "social_stream",
           "text": "Unverified claim regarding recent environmental developments...",
           "media_urls": [],
           "require_genie_audit": true
         }'
